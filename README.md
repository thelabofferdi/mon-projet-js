# mon-projet-js

Même script interactif que l'exercice 2 (chat, image, vidéo), mais écrit avec le SDK JavaScript `rodiumai`.

## Installation

Node 18 ou plus

```
npm install
```

## Configuration

```
cp .env.example .env
```

Puis mettez votre clé dans le fichier `.env`.

## Lancer

```
node main.js
```
